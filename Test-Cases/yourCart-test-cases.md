# Add to Cart Test Cases

## TC-001 Verify navigation back to Products page from the shopping cart

### Pre-Condtitions
1. The user is logged in and on the Products page (https://www.saucedemo.com/inventory.html)

### Steps
1. Click on the Shopping Cart icon (top-right corner)
2. Click 'Continue Shopping' button

### Test Data
username: standard_user,
password: secret_sauce

### Expected Result
1. User is redirected back to the Products page
2. Products listing page is displayed correctly


## TC-002 Verify navigation to Products details page from the shopping cart

### Pre-Condtitions
1. The user is logged in and on the Products page (https://www.saucedemo.com/inventory.html)
2. At least one product is added to the shopping cart

### Steps
1. Click on the Shopping Cart icon (top-right corner)
2. Click on the product name(title) button in the cart

### Test Data
username: standard_user,
password: secret_sauce

### Expected Result
1. User is redirected to the correct Product Details page
2. Products details match the selected item
